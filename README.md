**Фитнес-трекер: структуры и интерфейсы Go**

Учебный проект по обработке дневной активности и тренировок. Практика структур, встраивания, методов, интерфейсов, валидации и обработки ошибок. Расчёт калорий демонстрационный.

**Где смотреть решение**

[Ветка first](https://github.com/Articlik185/fitness-tracker-interfaces/tree/first) содержит реализацию. [Учебный PR №1](https://github.com/Articlik185/fitness-tracker-interfaces/pull/1) открыт. В main сохранён исходный шаблон.

**Структура**

- cmd/tracker — пример использования.
- internal/personaldata — данные пользователя.
- internal/daysteps — дневная активность.
- internal/trainings — тренировки.
- internal/spentenergy — расчёты.
- internal/actioninfo — общая обработка через интерфейс.

**Запуск и проверки**

Используйте версию Go, указанную в go.mod выбранной ветки, или новее:

    git switch first
    go test -v ./...
    go run ./cmd/tracker

Примеры содержат и корректные, и некорректные входные строки, чтобы показать обработку ошибок.

**Тестирование проекта**

Рядом с файлами, которые вы будете редактировать, находятся файлы с суффиксом _test.go. В них содержатся юнит-тесты, проверяющие корректность вашей реализации. Эти тесты автоматически запускаются на GitHub. Чтобы работа была зачтена, ваш код должен успешно проходить все тесты. Обратите внимание: изменять содержимое тестов запрещено.

Вы можете запускать тесты локально, выполнив следующие команды в корневой директории репозитория:

```bash
go mod tidy
go test -v ./...
```
